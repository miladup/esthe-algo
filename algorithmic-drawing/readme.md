Ces trois figures relèvent du dessin algorithmique (algorithmic drawing).

Les deux premières sont des adaptations de codes écrits à l’origine en GFA BASIC, retranscrits en p5.js.
La première, composée de rectangles concentriques, reprend une structure algorithmique simple à laquelle j’ai ajouté une variation de la couleur dans le temps.
La seconde est un dessin sinusoïdal statique, basé uniquement sur des calculs mathématiques.

La troisième figure, une grille de points animés utilisant le noise, est un choix personnel.
Elle s’inspire d’un exemple trouvé sur le site de p5.js, que j’ai modifié afin que les cercles ne se déplacent pas dans l’espace mais changent de taille dans le temps, produisant ainsi un mouvement fluide.

# Littérature numérique

## Description

Ce projet regroupe deux expérimentations en JavaScript et HTML :

### Lettres d’amour aléatoires

Génération automatique de lettres aléatoires combinant actions, sentiments et fragments, avec une nouvelle lettre toutes les 9 secondes.
Il s’agit d’une adaptation moderne de l’algorithme original de Christopher Strachey pour générer des lettres d’amour.

### SVG Flow "FORM"

Affichage du mot "FORM" comme ancre centrale, entouré de mots aléatoires avant et après pour créer un effet poétique et graphique.

- Les mots avant ("CREATING", "SHAPING", "BUILDING", etc.) apparaissent à gauche de "FORM".
- Les mots après ("IN SPACE", "IN MOTION", "OF LIGHT", etc.) apparaissent à droite de "FORM".
- Chaque ligne est générée aléatoirement pour créer un flux dynamique et visuel sur l’écran.

## Utilisation

Ouvrir les fichiers HTML dans un navigateur.

## Outils

HTML, CSS et JavaScript.

# Litérature digitale, ASCII art

## Description

Ce projet regroupe deux expérimentations en JavaScript et HTML :

### Lettres d’amour aléatoires

Génération automatique de lettres aléatoires combinant actions, sentiments et fragments, avec une nouvelle lettre toutes les 9 secondes.
Il s’agit d’une adaptation moderne de l’algorithme original de Christopher Strachey pour générer des lettres d’amour.

### ASCII art "LOVE"

Affichage du mot "LOVE" formé uniquement par le mot "LOVE", centré à l’écran et construit à partir d’un ASCII art simplifié.

## Utilisation

Ouvrir les fichiers HTML dans un navigateur moderne.

## Outils

HTML, CSS et JavaScript.
